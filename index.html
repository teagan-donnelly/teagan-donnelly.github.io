Hurricane Relief Coordination System

Current Status: Requirements & System Design

This project is actively in development. The team is currently finalizing system requirements and architecture before beginning Java implementation. This page will be updated as development progresses.

Full Stack Developer & Project Manager · 5-Person Team · Java

A Java-based hurricane relief coordination system designed to connect survivors requesting aid, volunteers offering skills and resources, and elief coordinators managing response efforts. I contribute as both a Full Stack Developer and Project Manager, with my work so far focused on requirements engineering, object-oriented system design, UML modeling, and preparing the architecture for implementation.

What I've Done:

  • Authored 61 functional requirements and subrequirements covering aid requests, emergency escalation, duplicate detection, account access, credential verification, permissions, and MFA.
  • Designed and refined the system's object-oriented class architecture, defining entities, relationships, responsibilities, enums, attributes, and methods for planned Java implementation.
  • Created use-case and sequence models to validate major workflows and system interactions across survivors, volunteers, coordinators, and administrators.
  • Lead coordination for a 5-person development team while contributing directly to technical design, requirements, and architecture.
